# F161

The lockout regression in miniature. An approved requirement says the third failed sign-in locks the account; the
test "allows a third failed attempt" passes, and its witness shows the third failure leaving the account unlocked. The
evidence violates the rule while every test is green. That is masked danger of the shape green over refuted: the
overview marks the one entry that carries the violation, names the obligation it refutes and the passing test that
reads as assurance, and marks nothing else. Analyse, danger and grain, section 3
([16](../../docs/spec/16-analyse-danger-grain.md)); exit of stage 56.
