# F82

Two version 2 witnesses carry no outcome. The executions file says the test that recorded `w1` failed, and the test
that recorded `w2` passed. Joined by test identity, `w1` is a witness whose test failed: it is reported as an
execution with outcome failed and is never lifted as a claim. `w2` is lifted as an example claim. Anchor, harnesses
and A3, sections 3.2 and 6.3 ([09](../../docs/spec/09-anchor-harness-a3.md)); exit of stage 11.
