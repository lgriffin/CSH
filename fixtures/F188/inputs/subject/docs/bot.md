# The bot

Anyone else gets "Only that night's officers can import its sign-ups." The same import is open to officers on the site.

Members can change their specs; either way, no later import touches them.

The import keeps only what the hub uses today.

A generic guild site cannot show that, because it depends on the guild's own analysis.

The bot does not import the API package.

Handlers must not, under any circumstances, import the database driver.

The import rules forbid the cogs from reaching the database.

The worker imports nothing from the web layer, because the web layer is optional.
