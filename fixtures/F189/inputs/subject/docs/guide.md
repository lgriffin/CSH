# Adding a test

1. Create `tests/cases/myTest.ts` with the test code and its directives.
2. Run the tests.

To add a fourslash test, create a new file `tests/fourslash/myTest_test.go` beside the others.

The build writes `tests/out/report.json` when it finishes.

You can touch `tests/cases/.keep` to keep the directory.
