# Cart requirements

| ID | Requirement |
| --- | --- |
| REQ-1 | WHEN an item is added, THE cart SHALL hold it. |
| REQ-2 | THE cart SHALL accept every positive quantity. |
| REQ-3 | THE cart total SHALL be the sum of its lines. |
| REQ-4 | IF a quantity is negative, THEN THE cart SHALL refuse it. |
| REQ-5 | THE cart parser SHALL never panic. |
