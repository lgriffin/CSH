# Developing

Run `npx hereby test` to test and `hereby build` to build. Cut a release with `hereby release`.

Run `make lint` before a commit; `make docs` builds the documentation.

Format with `just fmt` and deploy with `just d` or `just deploy production`. Publish with `just publish`.

Check with `pnpm run check`, and verify with `yarn run verify`.

A `make seed` target is not yet written.
