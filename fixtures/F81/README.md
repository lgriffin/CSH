# F81

The specification declares three sources: `Product`, `UnitTests` and `DesignNotes`. The component manifest names
only the first two in its practices. A source no practice names is reported as the gap `unowned-source`, with the
source as its subject. It is a gap, not an error: the run completes. Anchor, harnesses and A3, sections 2.1 and 6.4
([09](../../docs/spec/09-anchor-harness-a3.md)); exit of stage 10.
