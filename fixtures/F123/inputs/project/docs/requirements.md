# Order requirements

| ID | Requirement |
| --- | --- |
| REQ-1 | THE order total SHALL be the sum of its lines. |
| REQ-2 | IF a line is negative, THEN THE order SHALL be refused. |
| REQ-3 | WHEN a refund is full, THE order SHALL return every line. |
| REQ-4 | WHEN an order is placed, THE shop SHALL save it. |
