# F164

What danger is not. The test "locks on the third failure" fails, so its witness is no claim, and LockOnThirdFailure has
no evidence that decides it: the obligation is unknown, an honest answer, and stays indeterminate. A red test says what
it says. No rule is approved, so no approval reads as assurance. The unknown obligation and the red test are not
dangerous, and the unknown obligation is reported where it was. The one dangerous entry is the other test, "accepts the
correct password": it passes, and no rule constrains what it observes (test under no rule). Analyse, danger and grain,
section 3 ([16](../../docs/spec/16-analyse-danger-grain.md)); exit of stage 56.
