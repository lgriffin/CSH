# F163

Two approved requirements and one passing test. "accepts the correct password" exercises AcceptCorrectPassword, which
converges, but its approval is self-approved: the person who wrote the rule approved it, so the approval reads as
assurance it does not give. LockOnThirdFailure is approved and no example exercises it: an approved rule with silence
beside it. Both are masked danger, each with its own shape and the input that would close it (a second maintainer, a
boundary example). The stand-in authority marks AcceptCorrectPassword as self-approved, as the ledger does when the
approver is the author. Analyse, danger and grain, section 3 ([16](../../docs/spec/16-analyse-danger-grain.md)); exit
of stage 56.
