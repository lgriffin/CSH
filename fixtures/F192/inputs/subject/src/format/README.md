# Formatting

To format code you need a `SourceFile`. Formatting starts at `FormatSpan`, and the rules are requested via
`createRulesMap`, which caches them. The map is built by `buildRulesMap()`.

On Windows the watcher calls `ReadDirectoryChangesW`. The page is drawn by `TutorsShell`.

The `oldHelper` function was removed in 2.0.

```ts
const rules = fencedName();
```

A plain word such as `Format` or `rules` is prose.
