# Requirements

## R-A-1 Tasks start in todo

The board creates every new task in todo.

## R-A-2 Moves are checked

The board refuses a move the task's status does not allow.

## R-A-3 Lists keep their order

The board lists tasks in the order they were created.

- **Verified by:** `tests/b.test.ts`.

## R-A-4 The domain knows no transport

The domain imports nothing from the API.

## R-A-5 The API knows no tests

The API imports nothing from the tests.

## R-A-6 The domain knows no tests

The domain imports nothing from the tests.
