# Writing an A3

An A3 reads the findings on one component as one problem: what each practice says, where the harness says they
disagree, why, and what to change. Every number on it is counted from runs. Everything a person must say, they write
in one file, and the sheet marks it with its authority. The design is [09](../spec/09-anchor-harness-a3.md),
section 5; [the lockout A3](../../examples/lockout/csh/a3/three-practices/a3.md) is a finished one, and
[the gate's A3](../../packages/gate/csh/a3/dispositions/a3.md) is one just opened, waiting for its owner.

## 1. Open it from a run

```sh
csh run
git commit ...            # the run must be of a commit, not of a dirty tree
csh a3 open <slug>
```

`csh a3 open` records the run of HEAD as the first stage (`csh/a3/<slug>/stages/first/`), writes
`csh/a3/<slug>/judgments.json` with one lane per practice and every judged section empty, and builds the sheet. Every
signal shows as unclassified, and every empty section reads "Not yet written.", so a draft cannot pass for a finished
sheet. `open` never overwrites judgments that exist.

## 2. Place every signal

A signal is one item of a report: a finding, a gap, an error, a rule not comparable, or a violated rule. Each has a
kind, the fragments and sources involved, and the practices that own those sources. The judgments place signals with
structured rules:

```json
{ "id": "count", "name": "A count in prose read two ways",
  "match": [{ "kind": "example-conflict", "fragment": "LockOnThirdFailure" }, { "kind": "example-divergence" }] }
```

A rule matches when the signal has its `kind` and every other field it sets: `fragment` (the qualified name or its
last segment), `source`, `practice`, `subject` (for a gap; the item or its last segment), and not its `not` rule.
Causes place signals on the Pareto, lanes on the picture of hand-offs, and decision points in the table of what each
practice says. A signal no cause places is listed as `unclassified`; a rule that places nothing at any stage is
`dead-rule`.

## 3. Say what only a person can say

The background, what each practice cannot say (`cannotSay`, by practice id), the decision points and what each
practice says at each (`says`, by practice id), the goal, the root-cause questions with their answers, the 5 Whys, the
countermeasures and the plan. Evidence for an answer is a pointer the builder checks:

```json
{ "file": "src/lockout.ts", "text": "failedAttempts > MAX_FAILED_ATTEMPTS", "stage": "before" }
{ "finding": "d7620e8595d774a2", "stage": "before" }
```

A file pointer must quote text the file held at that stage's commit; a finding pointer must name a finding in that
stage's report. Either one that does not is `dangling-pointer`.

## 4. Say how each countermeasure will be verified

The sheet computes each countermeasure's status. `clears` names signals present at the first stage that must be gone
at a later one; `expects` names signals that must appear once it is in place; `stage` names a stage that must end with
the enforcing gate allowing; `measure` names a measure that must meet its target at the last stage. A countermeasure
with none of these is `unverifiable`, unless its kind is `scope` or `process`. A root-cause question no countermeasure
answers is `unanswered`.

## 5. Add stages, build, verify

```sh
csh a3 stage <slug> <id> --at <commit>   # copies that commit's stored run, or runs it
csh a3 build <slug>                      # writes a3.json, a3.md and a3.html beside the judgments
csh a3 build <slug> --check              # what CI runs: fails when the committed outputs differ
csh a3 verify <slug>                     # re-runs every stage at its commit and compares
```

Commit the stage records with the judgments, so the sheet reads correctly after its branches are gone.

## 6. Approve it

The judgments are candidate until an intent owner approves their digest through the ledger, as for an obligation:

```sh
csh approve '#a3/<slug>' --actor <name> --rationale <why>
git add csh/ledger.ndjson && git commit -S -m "approve #a3/<slug>"
```

Any later edit to the judgments changes the digest and returns the sheet to candidate. An A3 never changes a verdict or
a gate decision; it reads them.
